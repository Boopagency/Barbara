Pata em marca-d'água e grão: a textura de fundo dos slides sem foto.

- **Você fornece:** só a posição da pata (`bf-pata--td`, `--bd`, `--be`, `--te`; `--p` para a menor).
- A pata usa a cor do texto a 12% e sempre sangra para fora do slide. No máximo três por slide, nunca atrás de texto corrido longo.
- O grão vem sozinho em todo `.bf-slide`; não desligue.
- A pata deste sistema é um redesenho simples da usada nas artes. O padrão de focinho de gato e o pattern geométrico do manual ainda não têm arquivo: não tente redesenhá-los.

```html
<i class="bf-pata bf-pata--td"></i><i class="bf-pata bf-pata--bd"></i>
```
