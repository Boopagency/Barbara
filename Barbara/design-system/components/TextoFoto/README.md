Fundo liso com chamada, texto e uma foto de cantos arredondados que ocupa o resto do slide.

- **Você fornece:** chamada curta (`bf-punch`), até 25 palavras de texto e uma foto horizontal ou quadrada.
- Fundo `vinho` ou `ameixa`, com patas. A foto cresce sozinha até o fim da área de conteúdo.
