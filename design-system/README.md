# Design system · carrosséis da Barbara Fonseca

- `DESIGN-SYSTEM.md`: arquivo único para colar em qualquer Claude ou ChatGPT (regras, modelos em HTML e a folha de estilo inteira).
- `slides.css`: a folha de estilo dos slides (classes `bf-*`, 1080 × 1350 px), com o símbolo embutido.
- `tokens.json`: cores, tipografia, espaços e raios.
- `exemplo.html`: todos os modelos de slide montados com as fotos do site. Abra no navegador.
- `recortes/`: pacientes reais sem fundo, para o personagem destacado. As demais fotos da Barbara ficam só no Claude Design (algumas mostram voluntários).

A versão navegável (Claude Design) fica em https://claude.ai/artifact/PoWLU2hb7DEdhV77VsK1ec.
